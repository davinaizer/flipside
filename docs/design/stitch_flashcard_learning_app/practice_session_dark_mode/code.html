Caching

Question

When would you choose write-through caching over write-back?

Key Takeaways

Choose write-through when data consistency is strictly non-negotiable and resilience against crash loss is critical (e.g., financial transactions).

Write-back delivers higher write throughput with lower latency by lazily flushing dirty entries, but risks data loss during unexpected crashes or network partitions.
