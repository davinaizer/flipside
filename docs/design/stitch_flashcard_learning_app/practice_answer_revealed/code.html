Caching
Question

When would you choose write-through caching over write-back?

visibility Answer Revealed

  • Reads must always see the latest write immediately without delay.

  • Simpler crash recovery since persistent storage is always kept up to date.

  • Acceptable write latency trade-off because writes are significantly less frequent than reads.
